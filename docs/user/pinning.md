# Pinning

A pin is a screenshot that floats above every other window. Use it as a reference while you work.

## Creating a pin

- Hover a Quick Access card and press the pin button.
- Press `Ctrl+P` or the pin button in the editor (pins the edited image).
- Press the pin button on a history entry.

The pin opens in the middle of the monitor under the cursor, at full size or scaled to fit within 80% of the work area.

## Using a pin

| Input | Effect |
| --- | --- |
| Drag | Move |
| Scroll | Resize |
| `Ctrl` + scroll | Opacity (20% to 100%) |
| `+` / `-` | Zoom in / out |
| `0` | Reset to 100% |
| Arrow keys | Nudge 1 px (`Shift`: 10 px) |
| `Ctrl+C` | Copy the image |
| `L` | Toggle lock mode |
| `Esc` | Close |

Hover a pin for a toolbar: copy, edit (closes the pin and opens the editor), opacity presets, lock, close. The corner label shows zoom and opacity.

## Lock mode

A locked pin ignores the mouse: clicks pass through to the window below, and its hover toolbar is hidden.

To unlock, use **Unlock Pinned Screenshots** in the tray menu. That unlocks every pin.

Pins are not saved. They disappear when you close them or quit Snipsy.
