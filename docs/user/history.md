# History

Every capture is stored automatically, whatever the after-capture action. Open the window with `Ctrl+Shift+H` or **Open Capture History** in the tray menu.

## Browsing

- Filter by All, Area, Fullscreen, Window or Edited. Area also lists self-timer captures.
- Each entry shows its kind, date and pixel size.
- Single-click selects an entry. Double-click opens it in the [editor](annotating.md).

## Actions

Hover an entry for:

- Edit: open in the editor.
- Copy: copy the image.
- Pin: float it ([Pinning](pinning.md)).
- Delete: remove it and its files.
- **Restore**: send it back to [Quick Access](quick-access.md).

**Open Folder** shows the stored files. **Clear All** deletes every entry.

## Retention

Entries are kept for 1, 7, 14 or 30 days (default 30; Settings > Screenshots). Older ones are deleted when Snipsy starts. Entries whose file went missing are dropped at the same time.

Edited images appear here only when saved from the editor, as "Edited". Copying from the editor does not add an entry. Text captures are never stored.

Files live in the `history` folder inside the data folder. See [Settings](settings.md).
