# Text recognition

Snipsy copies text out of any part of the screen using the OCR engine built into Windows. Recognition runs on this PC; nothing is uploaded.

## Capture text

1. Press `Ctrl+Shift+2`.
2. Drag over the text.
3. A toast shows the first lines, and the full text is on the clipboard.

From All-In-One, press the **OCR** button, then select. If a selection already exists, **OCR** reads it immediately.

## From an existing capture

Press the bottom-right button on a [Quick Access](quick-access.md) card to read the text in that capture.

## Notes

- Recognition uses the languages in your Windows profile. If no OCR language pack is installed, Snipsy shows "Text recognition failed". Install one in Windows Settings > Time & language > Language & region.
- Small selections are upscaled first, which improves accuracy. Select a bit more than you need if results are poor.
- "No text found" means the engine saw nothing. Try a larger area.
- Text captures are not saved to [history](history.md) and no image is produced.
